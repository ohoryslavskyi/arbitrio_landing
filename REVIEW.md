# v7 — автоматизовані перевірки

23 тести у 5 файлах, vue-tsc та production-збірка пройшли через npm run verify. Покриття і команди описані в TESTING.md. Додано типи DOM-посилань і перевірку наявності елемента перед focus. Нижче — попередній звіт v6.

# Виправлення v6

- Тема відновлюється також під час запуску Vue, до монтування, зі спільним станом перемикача. Це працює і без початкового inline-скрипта. Якщо браузер повністю забороняє сховище, збереження між сеансами недоступне.
- Сітка використовує pointermove/pointerdown для миші та пальця, пасивні події не блокують прокручування.
- Верхні й нижні пари кнопок мають однакові розміри. Демо-кнопки названі «Спробувати демо» з відповідними перекладами чотирма мовами.
- Демо-кнопки отримали суцільну підсвітку для hover, active і клавіатурного фокуса, окремо для обох тем.
- Світла таблиця винагород: фон #f6f8fb, п'ятий рівень #e4e9f2 за референсом.
- Підписи бічного меню без підкладки, жирніші; синій колір при наведенні. Пункти мобільного меню також жирніші й без фону при наведенні.

Точні результати поточної версії: QA_RESULTS.json. Сценарій tests/fixes-v6.cjs перевіряє 390 і 1440 px, дві теми, чотири мови, збереження теми без inline-скрипта, фактичний дотик до сітки та рух миші, рівні розміри верхніх кнопок, колір підсвітки обох демо-кнопок, навігацію та переповнення.
