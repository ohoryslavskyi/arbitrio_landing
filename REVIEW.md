# Перевірка UI v4

## Зміни
- Мови: компактна кнопка з глобусом, кодом мови та маленьким трикутником за референсом; стилізований список збережено.
- Десктоп від 1200 px: замість хедера окремі кнопки мов і теми зверху праворуч; футер приховано.
- Мобільний хедер збережено; у бургері прибрано нумерацію.
- У світлій темі бічна навігація не має суцільної непрозорої підкладки. Світлі підписи отримали відповідний фон, активна крапка синя.
- Сітка першого екрана заповнює правий край без порожньої смуги.
- Текст під заголовком має анімований зелено-бірюзово-синій градієнт; при prefers-reduced-motion анімація вимикається.

## Перевірки
Chromium, Firefox і WebKit: 240, 320, 390, 440, 844, 1024, 1440, 1920 px; чотири мови й дві теми. 192 комбінації пройшли. Після останньої зміни ширини декоративної сітки повторено 440 і 1440 px в усіх трьох рушіях.

Перевірено переповнення документа/хедера, межі списку мов, перемикання й збереження теми та мови, клавіатурне керування, навігацію бургера, відсутність нумерації, прозорий фон бічного меню, відсутність десктопного хедера/футера та наявність анімації градієнта. Збірка та git diff --check успішні. Скріншоти: test-results/*-v4.png. Деталі: QA_RESULTS.json.

## Межі
Перевірені браузерні рушії, а не фізичні пристрої. Сам Safari на iOS/macOS, застосунки Chrome/Edge та браузер Telegram не запускалися. Старі повні профілі DevTools наведені в QA_BASELINE_V1.json і не є повторною перевіркою v4. Pinch фото окремо перевірявся у v2.

Зміни локальні, без публікації в GitHub або на сайті.
