# Arbitr.IO — дві теми, мобільна верстка та чотири мови

## Локальний запуск у Windows

Розпакуйте архів у нову папку. У PowerShell відкрийте папку `arbitrio_landing` з архіву й виконайте:

```powershell
npm ci
npm run dev
```

Відкрийте адресу з термінала, зазвичай `http://localhost:5173/presentation/`.

Для збірки:

```powershell
npm run build
```

В архіві також є готова папка `dist`. Вона призначена для HTTP-сервера на шляху `/presentation/`, а не для відкриття `index.html` подвійним кліком.

## Зміни

- v4: на десктопі окремі кнопки мов/теми без хедера і футера; мобільний бургер без номерів; анімований градієнт у першому екрані; прозора бічна навігація у світлій темі.

- Світла і темна теми. Кнопка сонця/місяця у хедері перемикає всю сторінку, вибір зберігається після перезавантаження. Світла тема має сіро-блакитне тло, білі картки й синьо-бірюзові акценти.
- У хедері використано той самий BrandLockup, що й у футері, включно з підписом на широких екранах.

- Стилізований dropdown мов у хедері: українська, російська, англійська, італійська. Перекладено всі активні секції, кнопки, меню, тарифи, підписи та текстові описи для доступності. Вибір зберігається у браузері; якщо сховище недоступне, перемикач продовжує працювати протягом сеансу.
- На мобільних є закріплений хедер із логотипом, бургером, мовами та перемикачем теми справа. Бургер відкриває повні назви секцій на окремій непрозорій панелі. Бічні крапки залишені лише на широких екранах.
- Мобільне фото команди показується повністю. Два пальці змінюють масштаб від 1× до 4×; збільшене фото можна переміщати одним пальцем. Кнопка скидає масштаб.
- Системна смуга прокрутки прихована, прокручування сторінки працює. Довгі написи переносяться на вузьких екранах.
- Шрифти Geist і Geist Mono включені локально з ліцензіями. Для стилів більше не потрібен запит до Google Fonts.

## Повторити перевірки

```powershell
npx playwright install
npm run test:responsive
npm run test:interactions
npm run test:header
$env:BROWSER = "firefox"
npm run test:responsive
$env:BROWSER = "webkit"
npm run test:responsive
Remove-Item Env:BROWSER
```

Сценарії використовують готову `dist`: перед перевіркою зміненого коду виконайте `npm run build`. Вони самі запускають локальний HTTP-сервер. Скріншоти інтерактивних перевірок записуються в `test-results`.

Каталог екранів: `tests/chrome-devtools-profiles.json`, отриманий із Chrome DevTools `EmulatedDevices.ts`: https://github.com/ChromeDevTools/devtools-frontend/blob/main/front_end/models/emulation/EmulatedDevices.ts . У ньому 46 пристроїв та 102 варіанти орієнтації/розкладеного стану. Перевіряються розмір viewport, щільність пікселів і touch/mobile-параметри; фізичні вирізи, шарніри та панелі системного браузера цим не відтворюються.

Точні результати й межі перевірки наведено в `REVIEW.md`.

## Перевірка наступних змін

Після `npm ci`: `npm run test` — 23 юніт/компонентні тести; `npm run check` — типи; `npm run verify` — типи, тести та збірка. Деталі в TESTING.md.
