# Перевірки перед змінами

Потрібен Node.js 22 LTS. Після розпакування один раз виконайте `npm ci`.

```sh
npm run test
npm run check
```

`test` запускає Vitest у режимі одного прогону й завершується з помилкою, якщо тест не пройшов. Браузери встановлювати не потрібно. `npm run test:watch` повторює тести після збереження файлів.

`check` запускає vue-tsc без генерації файлів: перевіряє JS через checkJs і JSDoc, Vue script/template та Vite-конфіг. Увімкнені strictNullChecks, noImplicitReturns, noFallthroughCasesInSwitch та контроль регістру шляхів. noImplicitAny поки вимкнений для поступової типізації наявного JavaScript — це не повна міграція на strict TypeScript. Перевірка не використовує @ts-ignore або виключення компонентів.

Одна команда для всіх обов'язкових локальних перевірок:

```sh
npm run verify
```

Вона послідовно виконує типи, юніт-тести та production-збірку й зупиняється на першій помилці.

## Що захищають тести

- preferences: відновлення теми без inline-скрипта; синхронізація стану, DOM і localStorage; недоступне сховище; переклади всіх мов, ключі, метадані та однакові назви демо-кнопок.
- navigation: бургер, усі сім пунктів, відсутність номерів, взаємне закриття меню, вибір мови, стрілки/End/Escape, зовнішній клік, повернення фокуса, desktop resize та кнопка теми.
- photo: звичайний скрол пальцем, pinch 1–4×, межі переміщення, скасування жесту та скидання.
- dynamics: активна секція при скролі й унизу сторінки, поріг видимості меню, реакція сітки на pointerdown/pointermove, прибирання слухачів; запуск партнерських шкал лише у viewport, завершення та reduced motion.
- landing: збірка всіх секцій у чотирьох мовах, унікальні ID, кожне внутрішнє посилання веде до наявної секції, узгоджені CTA.

Тести не дублюють кожен статичний абзац і CSS-властивість. JSDOM не відтворює реальну верстку й особливості Safari. Після змін CSS/жестів додатково запускайте на готовій збірці:

```sh
npx playwright install
npm run test:fixes
npm run test:header
npm run test:responsive
npm run test:interactions
```

Для іншого рушія задайте `BROWSER=webkit` або `BROWSER=firefox` (у PowerShell: `$env:BROWSER = "webkit"`). WebKit не замінює остаточну перевірку Safari на iPhone/macOS. Ці браузерні сценарії окремі від швидкої команди `npm run test`.

## v8

Vitest оновлено до 5.0.3. У vitest.config.js вимкнено transformAssetUrls лише для юніт-тестів: картинки public не імпортуються як file URL. Production-конфіг не змінено. Усі 23 тести, типи та збірка пройшли на Linux; Windows окремо не запускався.
