# Arbitrio — лого і favicon

Знак: дві лінії, що сходяться в літеру **A** — два ринки, які зустрічаються в одній ціні.
Перекладина зсунута вниз і тримає обидві ноги: закрита позиція.

Назва пишеться одним словом — **Arbitrio** (домен arbitrio.net). Крапки в назві немає.

## Файли

| Файл | Де використовувати |
| --- | --- |
| `arbitrio-mark.svg` | основний знак (градієнт), хедер сайту й панелі |
| `arbitrio-mark-flat.svg` | плоскі кольори — друк, дрібні розміри, e-mail |
| `arbitrio-mark-mono.svg` | одноколірний, бере `currentColor` — іконки, штампи, ч/б |
| `arbitrio-lockup.svg` | знак + назва + підпис, для презентацій і партнерських матеріалів |
| `favicon.ico` | іконка вкладки — працює всюди, знаходиться браузером без тегів |
| `favicon.svg` | іконка вкладки, сучасні браузери |
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | іконка вкладки, старіші браузери |
| `apple-touch-icon.png` (180×180) | ярлик на iOS |
| `favicon-192.png`, `favicon-512.png` | Android / PWA |
| `site.webmanifest` | манифест PWA |
| `og-image.png` (1200×630) | превʼю посилання в Telegram, Twitter, Facebook |
| `arbitrio-mark-256.png`, `arbitrio-mark-512.png` | знак на прозорому тлі — аватарки, Telegram, стікери |

## Правила

- Мінімальний розмір знака — 20 px по висоті. Нижче цього беріть `arbitrio-mark-flat.svg`.
- Вільне поле навколо знака — не менше висоти перекладини (≈ 1/8 висоти знака).
- Знак не обертати, не розтягувати непропорційно, не змінювати товщину ліній.
- На фото і кольорових фонах — `arbitrio-mark-mono.svg` у білому, а не градієнтний.
- Не ставте градієнтну назву на світлий фон без заміни градієнта (див. вище).

## Що робити з поточним зеленим знаком

Зелений трикутник виводиться з обігу: він конфліктує з синьою палітрою продукту й розсипається
на 16 px. Заміна — один до одного, ті самі місця: хедер панелі, хедер лендінгу, вкладка браузера,
аватарка в Telegram, підпис у листах.
