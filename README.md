# Arbitrio — лендінг (Vue 3 + Vite)

Односторінковий лендінг Arbitrio: hero, команда, місія, платформа, навчання,
партнерська програма, тарифи, CTA. Плюс хедер продукту у двох станах.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # збірка в dist/
npm run preview  # локальний перегляд збірки
```

Залежності: Vue 3 і Vite. Більше нічого — ні UI-бібліотек, ні CSS-фреймворків.

⚠️ У `npm run dev` підшлях не видно — dev-сервер обслуговує корінь. А от
`npm run preview` віддає сторінку саме за `/presentation/`, як у проді.

## Адреса у проді — `https://arbitrio.net/presentation/`

Не апекс: апекс — це вхідні двері, єдиний вхід клієнтів у систему, і забирати його
під маркетинг не можна.

🔴 **Підшлях зашитий у двох місцях, і вони мусять збігатися:**

| Де | Що |
| --- | --- |
| `vite.config.js` (тут) | `base: '/presentation/'` — з ним усі посилання на статику збираються з префіксом |
| `admin-saas/Caddyfile` (репозиторій ArbBot) | `handle_path /presentation/*` → `landing:8080` — знімає префікс і веде в наш контейнер |

Розійдуться — сторінка віддасть порожній екран: HTML доїде, а бандл браузер попросить
не за тією адресою. Місця тепер у РІЗНИХ репозиторіях, тож grepом їх не звірити:
стереже димова перевірка деплою, яка стукає в цей URL і тягне бандл, названий індексом.

## Як тут прийнято

**Стилі — `<style scoped>` у компоненті.** Кожна секція носить свій CSS із собою:
компонент можна перенести в інший проєкт одним файлом. У `base.css` лежить тільки
те, що спільне: токени, шрифти, keyframes і три патерни hover для карток.

**Токени — CSS-змінні** в `:root`. Кольори ніде не дублюються літералами, крім
градієнтів (там потрібні конкретні стопи).

**Текст — у `data/content.js`.** Повторювані блоки (картки платформи, рівні,
штрафи) рендеряться `v-for` з масивів. Копірайтинг погоджений з власником —
правити тільки за його запитом.

**Анімації — composables.** Обидві прибирають слухачі й скасовують кадри при
демонтажі, обидві поважають `prefers-reduced-motion`.

## Три патерни hover

Уся сторінка тримається на трьох класах із `base.css` — нових вигадувати не треба:

| Клас | Ефект | Де |
| --- | --- | --- |
| `.card--lift` | `translateY(-6px) scale(1.03)` + синя рамка + тінь | показники, сценарії місії, картки платформи, кроки навчання |
| `.card--raise` | `translateY(-5px)` + синя рамка + тінь | тарифи |
| `.card--glow` | тільки рамка й тінь | обгортки з інтерактивними рядками всередині |
| `.row-hover` | фон `#101A28` + зсув `padding-left` на 4px | рядки винагород |
| `.chip-hover` | власна плашка під пунктом списку | «Що отримує партнер» |

`.card--glow` не піднімається спеціально: інакше рядки всередині «тікали» б
з-під курсора.

## Анімації

### Сітка квадратів за hero — `usePointerGrid`

Квадрат у радіусі 150px від курсора збільшується до `scale(1.26)`, світлішає,
отримує світіння і тягнеться до мишки. Сила падає квадратично (`e = (1 - d/R)²`),
тому пляма має мʼякий край.

Кількість квадратів рахується з реального розміру контейнера і перераховується
на `resize`. Стилі пишуться напряму в `element.style`, координати мишки — у
`requestAnimationFrame`: 260+ вузлів на кожен рух курсора — саме той випадок,
коли реактивність тільки шкодить.

### Шкали рівнів — `useLevelBars`

`IntersectionObserver` запускає відлік один раз, коли таблиця входить у вікно.
Композабл віддає `progress` від 0 до 1 (easing `1 - (1-t)³`, 2000ms), а шаблон
множить на нього свої цільові відсотки. DOM не чіпається.

### Решта

- `dotPulse` — точка «живого» стану в hero-плашці й у хедері.
- `flameDance` — 🔥 біля «до 90%» коливається постійно, при наводі на картку
  розжарюється (`saturate(2) hue-rotate(-16deg)`).
- `sheen` — блиск пробігає по картці показника при наводі.
- `.stat-bar` — синя смуга внизу картки розкривається злива направо.

## Хедер

`AppHeader.vue` **не змонтований** в `App.vue`: лендінг за задумом власника
без хедера. Компонент лежить готовий для панелі продукту:

```vue
<AppHeader :authenticated="false" active="terminal" />   <!-- гість -->
<AppHeader :authenticated="true" active="dashboard" />   <!-- у системі -->
```

| Стан | Права група |
| --- | --- |
| `authenticated: false` | «Увійти», «Отримати доступ», іконка теми (сонце/місяць) |
| `authenticated: true` | `Live`, сповіщення, перемикач «Темна / Світла» |

Тема пишеться в `data-theme` на `<html>` і в `localStorage`. Світлі стилі —
через `:global([data-theme='light'])` у самому компоненті.

Градієнт назви прив'язаний до пікселів (`#F2F6FB 0px → #7FD4FF 104px` +
`background-size: 104px 100%`), **не до відсотків**: інакше він розтягується під
розмір елемента й на різних кеглях виглядає по-різному.

## Заміна фото в секції «Команда»

Покласти свій файл як `public/team-masks.png` — компонент підхопить його сам.
Шлях в одному місці: `TeamSection.vue`, атрибут `src`.

## Що варто знати перед правками

- Секції незалежні: кожну можна прибрати з `App.vue`, нічого не зламається.
- Числа тарифів і рівнів зашиті в `content.js`. Якщо стануть динамічними —
  міняється тільки джерело масивів, шаблони лишаються.
- Емодзі на сторінці лише два: 🔥 у показниках і 🎓 у навчанні. Більше не додавати.
- Теплий колір (`--warm`) використовується виключно в блоці «Штрафи».
